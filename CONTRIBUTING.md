# Как помочь проекту

Нашли ошибку или придумали улучшение — создайте [Issue](https://github.com/alexaistudio/FamilyTasks/issues) и коротко опишите ситуацию. Для ошибки полезно указать версию Android и шаги, после которых она возникает. Не прикладывайте реальные семейные данные, recovery-коды, токены и адреса личных серверов.

Уязвимости не публикуйте в Issues: используйте [приватное сообщение о проблеме безопасности](https://github.com/alexaistudio/FamilyTasks/security/advisories/new).

Pull request может быть принят только после отдельного письменного соглашения с владельцем о правах на вклад. Это нужно для сохранения единого владения исходным кодом и возможности выдавать коммерческие лицензии.
