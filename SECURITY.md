# Безопасность

Если вы нашли уязвимость, отправьте [приватный GitHub Security Advisory](https://github.com/alexaistudio/FamilyTasks/security/advisories/new). Не публикуйте подробности в Issues до исправления и не прикладывайте реальные семейные данные, recovery-коды, токены или доступы к серверу.

Ключи подписи, пользовательские данные, recovery-секреты и параметры развёртывания не хранятся в этом репозитории.
