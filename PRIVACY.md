# Приватность

FamilyTasks не содержит рекламы, аналитики, трекеров, Firebase и облачной телеметрии. Разработчик не получает ваши дела и не собирает статистику использования приложения.

## Что хранится на телефоне

Дела находятся в зашифрованной SQLCipher-базе. Ключ базы и ключи синхронизации защищены Android Keystore. Уведомления создаются на самом телефоне: названия задач не отправляются в Google или другой push-сервис.

Диагностический журнал хранит только последние 100 событий синхронизации. В нём есть время, тип события и сокращённые технические идентификаторы, но нет названий дел, имён участников и ключей. Журнал покидает телефон только тогда, когда пользователь сам сохраняет файл.

## Что передаётся при синхронизации

Перед отправкой семейные данные сжимаются и шифруются AES-256-GCM.

- При Bluetooth-синхронизации телефоны обмениваются данными напрямую после проверки общего recovery-ключа. Системное Bluetooth-сопряжение не создаётся.
- При серверной синхронизации сервер получает зашифрованный пакет, случайные технические ID и токен устройства. В журналах хостинга также могут остаться IP-адрес, время и размер запроса. Названия, заметки, даты, имена участников и recovery-ключ серверу не передаются в открытом виде.
- GitHub используется только для проверки и загрузки официальных обновлений.

Камера включается только по действию пользователя для сканирования семейного QR-кода. Разрешения Bluetooth нужны для поиска другого телефона с FamilyTasks и прямого обмена данными.

## Как удалить данные

Локальные данные удаляются при очистке данных приложения или его удалении средствами Android. Команда удаления аккаунта в админке `sync.php` удаляет устройства и зашифрованные пакеты с вашего сервера.
