# Свой сервер синхронизации

Сервер FamilyTasks — это один файл [`sync.php`](sync.php). Он работает на обычном хостинге с PHP 8.1+ и PDO SQLite. Отдельная база данных или backend-приложение не нужны.

## Установка

1. Создайте на хостинге отдельную папку и загрузите в неё `sync.php`.
2. Убедитесь, что PHP может использовать SQLite.
3. Откройте `sync.php` в браузере и задайте пароль администратора.
4. В админке создайте одноразовый код для семьи или нового телефона.
5. На телефоне откройте настройки FamilyTasks, укажите адрес `sync.php` и введите код.

По умолчанию база создаётся на один уровень выше папки со скриптом, в каталоге `familytasks-private`. Этот каталог должен находиться **вне `public_html`**. Если хостинг устроен иначе, задайте абсолютный путь через переменную окружения `MYCALENDAR_DATA_DIR`.

## HTTPS и свой сертификат

Лучше использовать HTTPS. Подойдёт домен или прямой IP-адрес. Для самоподписанного сертификата приложение умеет закреплять его SHA-256-отпечаток:

```bash
openssl x509 -in cert.pem -noout -fingerprint -sha256
```

HTTP не раскрывает содержимое дел — оно уже зашифровано на телефоне, — но позволяет перехватить одноразовый код или токен устройства. Такой токен не расшифрует задачи, однако с ним можно выдавать себя за телефон и мешать синхронизации. В недоверенной сети используйте HTTPS.

## Какие данные видит сервер

Сервер хранит сжатые и зашифрованные AES-256-GCM пакеты. Семейный recovery-ключ остаётся на телефонах, поэтому без него нельзя прочитать названия, заметки, даты и имена участников.

Хостинг всё равно видит обычные технические данные соединения: IP-адрес, время и размер запроса. Владелец сервера также может удалить или задержать пакеты, но не может незаметно изменить их содержимое: повреждённый пакет будет отвергнут.

Команда удаления аккаунта в админке каскадно удаляет устройства и все зашифрованные пакеты этой семьи.

## Как происходит обмен

Клиент делает короткую проверку новых данных с выбранным пользователем интервалом. После локального изменения запускается внеочередная синхронизация. Полный зашифрованный снимок отправляется только тогда, когда данные действительно изменились.
